# Planilha da turma: aba "Projeto Ferramenta", coluna Grupo 7

Para colar na terça, campo por campo.

**Modalidade**
Imagem + voz (desenho e fala de criança → criatura de jogo)

**Título**
O bestiário do Samuel

**Sinopse**
Ferramenta para crianças de 6 a 9 anos criarem as criaturas do próprio mundo. A criança desenha o bicho no papel e conta, falando, como ele é. A IA junta o desenho e a fala, propõe versões e comportamentos, e a criança escolhe. A criatura vai para o bestiário dela, entra no Minecraft e sai como carta para imprimir.

**Ferramentas, Tecnologias ou Modelos usados ou experimentados**
App web para tablet; transcrição de fala por API (ex.: Whisper); modelo multimodal de imagem + texto para interpretar o desenho e propor aparência e comportamentos; geração de add-on .mcaddon para Minecraft Bedrock; agentes de código no desenvolvimento.
